# Небольшой гайд по сравнению методов

Чтобы сравнить методы численного моделирования на примере модели SIRVD, необходимо использовать модуль (скрипт) `comparison`:

```bash
python -m comparison
```



Скрипт можно запустить без аргументов, чтобы запустить стандартное сравнение всех методов для набора `h = [1.0, 0.5, 0.1]`. Скрипт так же принимает следующие аргументы:

```bash
methods=method1,method2,...,methodN				# методы для сравнения
hs=value1,value2,...,valueN										# рассматриваемые шаги h
out_dir=folder														  # папка, в которую сохраняются .csv (пока что авто-удаление)
```



Скрипт автоматически запускает моделирование для всех выбранных методов и размеров шага. Параметры системы установлены по умолчанию, однако их также можно задать через аргументы (например, `n=1000000 a=0.25 b=0.0005 t_end=365`).



Результатом сравнения является таблица с накопленными ошибками методов по сравнению с «эталонным методом» (RK56). Например:
